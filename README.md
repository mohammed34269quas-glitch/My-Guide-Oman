# دليلي عُمان

## تشغيل المعاينة

افتح `index.html` في المتصفح أو شغّل خادماً محلياً من هذا المجلد. تسجيل الدخول الحقيقي يحتاج اتصالاً بالإنترنت ومشروع Firebase.

## تفعيل الحسابات

1. أنشئ مشروعاً في Firebase وفعّل Email/Password من Authentication.
2. أنشئ قاعدة Firestore.
3. انسخ إعدادات تطبيق الويب إلى `firebase-config.js`. إعدادات Firebase الموجودة في المتصفح ليست أسراراً؛ قيّد مفتاح API بالنطاقات والخدمات المطلوبة.
4. ثبّت Firebase CLI، اربط المشروع، ثم انشر القواعد:

   ```sh
   firebase login
   firebase use --add
   firebase deploy --only firestore:rules
   ```

5. أنشئ عملية إدارية آمنة باستخدام Cloud Functions أو خادم موثوق لمراجعة طلبات المرشدين وإنشاء ملف المرشد المعتمد. لا تضع مفاتيح Admin SDK أو صلاحيات الإدارة في المتصفح.

قواعد Firestore الحالية تسمح للسائح بإنشاء ملف ثابت بدور سائح فقط، وتمنع المستخدم من تغيير دوره أو تعديل ملفه. طلب المرشد يبقى معلقاً، ويحتاج اعتماداً من الخادم. تسجيل الدخول لا يكتمل قبل إعداد Firebase.

## اللغات والتقنيات

- HTML وCSS وJavaScript: الواجهة الحالية وسلوك البحث والحسابات.
- Firebase Authentication وFirestore Rules: تسجيل الحسابات والتحكم بالوصول.
- TypeScript مع Cloud Functions: مناسب للمهام الخلفية مثل اعتماد التراخيص والحجوزات والإشعارات.
- Dart مع Flutter: خيار مناسب لاحقاً لتطبيق Android وiOS والويب من قاعدة كود واحدة.
- C++: غير مطلوب لهذا المنتج؛ يفيد عادة في المحركات والمهام عالية الأداء، وإضافته هنا ستزيد التعقيد دون فائدة للمستخدم.

لا تتضمن هذه النسخة الدفع أو الدردشة أو اعتماداً آلياً للرخص. لا ترفع وثائق الهوية إلى قاعدة عامة، ولا تخزن بيانات البطاقات؛ استخدم مزود دفع معتمداً وصفحة دفع مستضافة عند بناء هذه الأجزاء.
